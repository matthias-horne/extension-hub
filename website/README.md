# Gardener Extensions Hub

A curated grid of extensions for Gardener, styled after the official Gardener documentation.

## 🚀 Getting Started

### Installation
```bash
cd website
bun install
```

### Development
```bash
bun run dev
```

### Build
```bash
bun run build
```

## 🎨 Theming
The project uses Tailwind CSS and is themed with the Gardener color palette:
- **Brand Green**: `#009f76`
- **Green 1**: `#18794e`
- **Green 2**: `#299764`
- **Green 3**: `#30a46c`
- **Soft Green**: `rgba(16, 185, 129, 0.14)`
